# Python Data Modeling Portfolio

This folder contains hands-on projects for Python data analysis and data
engineering:

- [PU Foam Manufacturing Analysis](./data_modeling/README.md): clean and
  analyze production data with Pandas, then generate a report and charts.
- [Retail Sales ETL, SQL, and BI](./retail-sales-etl-sql-bi/README.md): load
  CSV or Excel data into a relational SQLite model, run SQL analytics, and
  prepare data for Power BI.
